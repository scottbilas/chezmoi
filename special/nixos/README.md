# special/nixos

NixOS **system** configuration. These files go in `/etc/nixos/` on NixOS machines.

This is not home-manager config. User packages and dotfiles are managed separately
via `~/.config/nix` (chezmoi-deployed, same flake used on macOS).

## Setup

See [NixOS Bringup](../../README.md#nixos-bringup) in the root README.

## Files

| File | Purpose |
|------|---------|
| `configuration.nix` | Shared system config for all machines |
| `desktop-light.nix` | XFCE — low-resource machines |
| `desktop-heavy.nix` | GNOME — VMs and capable machines |
| `hardware-pi.nix` | Boot config for Raspberry Pi / extlinux |
| `bootstrap.sh` | Setup script — fetches files, generates `profile.nix` |
| `profile.example.nix` | Example of what `bootstrap.sh` generates — keep in sync with the heredoc in `bootstrap.sh` |
| `profile.nix` | **Not in repo** — generated by `bootstrap.sh` (hostname, timezone, user, SSH key, ZeroTier network) |
| `hardware-configuration.nix` | **Not in repo** — generated by `nixos-generate-config` |
